# 📋 دليل المدربين والأندية الرياضية (Coach & Club Registration Guide)

دليل المدرب المعتمد لتسجيل عدائي النادي في البطولات والمنافسات الرسمية.

---

## 1. الدخول إلى معالج تسجيل العدائين
- من القائمة العلوية، اختر **"بوابة المدربين والأندية"** أو استخدم الرابط المباشر:
  `http://localhost:5173/?tab=coach`

---

## 2. خطوات التسجيل الأربع (Registration Wizard)
1. **الخطوة الأولى: اختيار البطولة والتخصص:**
   - تحديد البطولة الرسمية المعتمدة (مثال: سباق 100م رجال، 1500م، الوثب العالي، إلخ).
2. **الخطوة الثانية: اختيار العدائين وفحص الأهلية الآلي:**
   - تظهر فقط قائمة عدائي النادي التابع للمدرب (عزل أمني تام).
   - يقوم النظام تلقائياً بفحص:
     - سريان الشهادة والفحص الطبي.
     - تطابق الجنس والفئة العمرية مع لوائح World Athletics.
     - في حال وجود مانع، يُعلم النظام المدرب بسبب عدم الأهلية.
3. **الخطوة الثالثة: الأرقام التأهيلية والصدرية:**
   - إدخال الأرقام القياسية الشخصية (PB / SB) لتوزيع السلاسل والتصفيات (Heats).
   - اقتراح أرقام الصدريات الرسمية.
4. **الخطوة الرابعة: المراجعة واستخراج سند المشاركة:**
   - مراجعة الاستمارة النهائية.
   - تأكيد الإرسال وإصدار إيصال المشاركة الرسمي مع رقم الوثيقة المعتمد.
