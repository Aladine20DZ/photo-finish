# 👑 دليل استخدام لوحة الإدارة التنفيذية للرابطة (League Executive Guide)

يوضح هذا الدليل لمسؤولي الرابطات والاتحادات كيفية إدارة الأندية، اعتماد المنافسات، وإصدار التراخيص المشفرة.

---

## 1. الدخول إلى لوحة الإدارة التنفيذية
- من شريط التنقل العلوي، اختر تبويب **"إدارة الرابطة والاتحاد"** أو افتح الرابط:
  `http://localhost:5173/?tab=league`
- للأمور الحساسة وإدارة التراخيص الشاملة، يمكن الدخول عبر:
  `http://localhost:5173/?admin` (مع إدخال كلمة مرور `ADMIN_PORTAL_PASSWORD`).

---

## 2. وظائف الإدارة التنفيذية
1. **المؤشرات الرياضية الحية:**
   - متابعة عدد الأندية المنتسبة، العدائين المسجلين، والمنافسات المعتمدة.
2. **اعتماد المنافسات والروزنامة الرسمية (Sanctioning):**
   - مراجعة طلبات تنظيم البطولات الولائية والوطنية.
   - الموافقة على البطولة لنشرها في البوابة العامة وتعيين الحكام الرسميين.
3. **توليد التراخيص المشفرة (Ed25519 Cryptographic Licensing):**
   - إصدار أكواد ترخيص رسمية بصيغة `PFP2`.
   - تحديد الفئة (`ENTX` للاتحادات، `CLB8` للأندية) ومدة الصلاحية ورمز الجهاز أو الشبكة المشتركة (`POOL` لربط 4 هواتف).
4. **سجل الرقابة والتدقيق (Immutable Audit Trail):**
   - مراقبة كافة العمليات الإدارية وتعديلات النتائج لضمان النزاهة الرياضية ومنع أي تلاعب.
